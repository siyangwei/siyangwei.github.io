3. 基本工作流程

Git 有三个核心区域：

  • 工作区（Working Directory）：你实际编辑的文件
  • 暂存区（Staging Area/Index）：准备提交的更改
  • 本地仓库（Repository）：提交后的历史记录

9. 常用命令速查表

命令 说明
git init 初始化仓库
git add <file> 添加文件到暂存区
git add . 添加所有更改
git commit -m "msg" 提交更改
git status 查看状态
git diff 查看工作区差异
git log --oneline 查看提交历史
git log --graph --all 图形化查看分支
git reflog 查看操作记录
git reset --soft HEAD~1 软回退（保留修改）
git reset --mixed HEAD~1 混合回退（默认）
git reset --hard HEAD~1 硬回退（丢弃修改）
git checkout -- <file> 撤销工作区修改
git reset HEAD <file> 撤销暂存区修改
git commit --amend 修改最后一次提交
git branch 查看分支
git branch <name> 创建分支
git checkout <branch> 切换分支
git checkout -b <name> 创建并切换分支
git merge <branch> 合并分支
git stash 储藏临时修改
git stash pop 恢复储藏
git tag <name> 创建标签
git clean -fd 清理未跟踪文件

总结

Git 的核心就是围绕 工作区 → 暂存区 → 本地仓库 这三个区域的流转。

最重要的保命命令：

  1. git reflog —— 后悔药，能找回几乎所有操作
  2. git status —— 随时查看当前状态
  3. git log --oneline —— 快速查看历史

多练习，尤其是 git reset 的各种模式，这是本地版本控制的核心技能。
