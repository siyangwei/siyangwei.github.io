windows 和 Ubuntu 双系统时间问题怎么处理

  • Windows：默认将硬件时钟视为 本地时间（Local Time）
  • Ubuntu/Linux：默认将硬件时钟视为 UTC 时间（协调世界时）

当你从一个系统切换到另一个时，时间就会相差 8 小时（或你所在时区的偏移量）。

这是更现代、更合理的做法，避免 Linux 去迁就 Windows。

额外建议

  1. 关闭自动时区同步冲突：确保两个系统都开启了网络时间同步（NTP），这样即使硬件时钟有偏差，也能快速自动校正。

    • Windows：设置 → 日期和时间 → 自动设置时间
    • Ubuntu：timedatectl set-ntp true

  2. 时区设置正确：两个系统都要设置为你实际所在的时区（如 Asia/Shanghai）。

总结：推荐方案一（改 Windows 用 UTC），因为这是 Linux 世界的标准做法，且不会导致系统间的时间逻辑混乱。如果 Windows 端出现问题，再改用方案二。
