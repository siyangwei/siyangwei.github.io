Ubuntu22.04 waydroid 安装使用

发表于2026-06-03|更新于2026-08-17
|阅读量:

1. 安装

  • 添加 waydroid 官方源
  • apt 安装 waydroid

2. 初始化

默认点击应用图标，点击 download 下载 system.img 和 vendor.img 太慢了

这里选择手动下载

  • 下载 system.img 和 vendor.img

sourceforge 官网下载：https://sourceforge.net/projects/waydroid/files/images/

  • 解压 system.img 和 vendor.img 并放至指定目录
  • 初始化 waydroid

3. 安装 ARM 转译

初始化后可以正常使用 waydroid 但是还不能使用 arm 版的 app, 安装指令翻译工具 libhoudini（AMD CPU 可以安装 libndk）

  • 安装工具
  • 下载 waydroid-scrip
  • 进入下载得到的 waydroid_script 目录，安装

交互选择：选择安卓版本 ➡️ 选择安装操作 ➡️ 空格选中libhoudini ➡️ 回车下载

4.设置网络

waydroid 容器是通过 waydroid0 虚拟网口进行访问外网的，将 waydroid0 的 nat 转发到我们实际上网的网卡 wlan0/eth0

5. 共享文件夹

对于任何容器或虚拟系统而言，共享目录都是一个重要的功能，在 WayDroid 内也提供了一个轻松建立共享文件夹的机制，本文会概述如何对该功能进行快速的上手。

对于 WayDroid 而言，在进行初始化时会在 /var/lib/wadroid/images 内将文件系统和安全系统下载下来，然后首次运行时，会对 system.img 和 vendor.img 进行解压，具体路径为 ~/.local/share/waydroid。

对于安卓系统而言，一般的 Download、Movies 等目录会存放在 Data 目录下面，可以通过命令 sudo ls ~/.local/share/waydroid/data/media/0/ 查看目录结构的相信信息，然后安装下方的命令将本机的文件夹挂载到 WayDroid 的目录下，在完成挂载之后，宿主机和 WayDroid 容器之间就可以分享文件了。

或者，你也可以直接将内部存储挂载到主机上的目标文件夹，使用 bindfs 设置用户为所有已挂载文件的所有者（原始所有者权限保留在源文件夹中）。
